What is NightMC?

NightMC is a private Minecraft minigame network that I have been developing as a long-term personal project. It was created to enjoy custom multiplayer experiences with friends, and the project has grown into a network with a variety of minigames, cosmetics, and custom mechanics.

This repository isn't showcasing my whole project, but it includes sample files for an overall idea.
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
What this Contains:
- File listing all features in the plugin currently.
- Sample Main Minigame Method File: Tower Clash
- Sample Party System Main Methods.
- Cosmetic System overview with evolutions, with 2 sample cosmetics.
- Main Crates Open Method (Nightboxes)
- Sample Preferences Menu. 
- Sample Currency Method, Coins.
- Sample Rank System Containing Enum and Main Rank Class.
